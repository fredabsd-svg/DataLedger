# Propostas de logo — prancha para escolha

Pasta **temporária**, para o Fred escolher a direção do símbolo do DataLedger.
Sai do repositório assim que a escolha for instalada em
`docs/assets/logo-dataledger.svg`. Não deve ser integrada à `main`.

Quatro direções, nenhuma delas conta T, monograma ou infinito. Cada prancha
mostra a marca em 128 px (topo do README) e em 32 px (aba do navegador), sobre
fundo escuro e claro, com o custo de cada escolha declarado.

| Prancha | Direção | Ideia |
| --- | --- | --- |
| [A](A-selo-de-conferencia.png) | Selo de conferência | O carimbo: conferiu, bateu, carimbou. Disco azul-marinho com a marca de conferido em verde |
| [B](B-equilibrio.png) | Equilíbrio | Balança de dois pratos: os dois lados pesam o mesmo |
| [C](C-fita-de-somar.png) | Fita de somar | A bobina da calculadora de mesa, com os lançamentos e o total destacado |
| [D](D-livro-aberto.png) | Livro aberto | O livro-razão aberto, com o marcador na página certa |

Os arquivos `.dc.html` e `canvas.json` são a fonte das pranchas, no formato do
canvas de design; as imagens foram renderizadas a partir deles.
